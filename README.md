
# 🎮 Connect Four - Blazor Web App

A web-based implementation of the classic **Connect Four** game, built with Blazor and C#.

The objective is simple: be the first player to connect four discs in a row, either horizontally, vertically, or diagonally!

## ✨ Features

- Interactive Connect Four gameplay.
- Two-player game experience.
- Classic Connect Four rules.
- Win detection (horizontal, vertical, and diagonal).
- Dynamic game board updates.

## 🛠️ Technologies Used

- **C#**
- **Blazor**
- **.NET**
- **HTML / CSS**

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [.NET SDK](https://dotnet.microsoft.com/download)
- [Visual Studio](https://visualstudio.microsoft.com/) or [Visual Studio Code](https://code.visualstudio.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR-REPOSITORY
   ```

3. Run the application:

   ```bash
   dotnet run
   ```

4. Open the local URL displayed in your terminal to start playing!

## 🎯 How to Play

1. Two players take turns dropping their discs into the columns.
2. Each disc occupies the lowest available position in its selected column.
3. The first player to connect four discs horizontally, vertically, or diagonally wins.
4. Have fun!
